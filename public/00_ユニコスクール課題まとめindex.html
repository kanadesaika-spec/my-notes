🖥️ Claudeデスクトップ導入編 — 5ノート

Claude Codeの導入から基本操作までの出発点シリーズ。

  1. Claudeデスクトップ導入編/01_Claude_Codeを導入しよう — インストール・アカウント・Proプラン加入
  2. Claudeデスクトップ導入編/02_シューティングゲームを作ろう — はじめての開発体験（基本操作の型）
  3. Claudeデスクトップ導入編/03_ホームページを作ろう — プロンプト1つでデザイン付きHPを作る
  4. Claudeデスクトップ導入編/04_業務効率化ツールを作ろう — 裏側の業務システムのモックを作る
  5. Claudeデスクトップ導入編/05_Claude_Code_Desktopを使いこなそう — 複数セッション・権限モード・2画面

📚 Obsidian編（知識を集めて発信する）— 5ノート

「情報が自動で集まり、記事になり、発信され、安全に保管される」個人メディア工場を作るシリーズ。

  1. Obsidian編/01_YouTubeから情報取得して動画をテキスト化しよう — 動画→テキストのインプット収集
  2. Obsidian編/02_音声をテキスト化する文字起こしシステム — 音声→テキスト＆/transcribe自動化
  3. Obsidian編/03_整理した情報からブログ記事を作ろう — 裏付け付きブログ記事の自動生成
  4. Obsidian編/04_ブログ記事を図解や解説記事などに展開しよう — 1記事を多形式に展開＋全自動化
  5. Obsidian編/05_保管庫をGitHubで管理しよう — バックアップ・履歴管理・GitHub Actions

⚙️ ClaudeCode機能編（仕組みを理解する）— 8ノート

Claude Codeの中核機能を1つずつ習得するシリーズ。

  1. ClaudeCode機能編/01_SubAgentを作って起動してみよう — 専門担当AI（分身）を作る
  2. ClaudeCode機能編/02_Skillsを作って発動してみよう — 専門知識のパッケージを作る
  3. ClaudeCode機能編/03_SubAgentにSkillsを紐づけて自動ロードさせよう — 担当AIにマニュアルを持たせる
  4. ClaudeCode機能編/04_Skillsでエージェントを連携しよう — 分析→構築→検証のパイプライン
  5. ClaudeCode機能編/05_Planモードとgoalコマンドを試そう — 計画レビューと完了条件で自走
  6. ClaudeCode機能編/06_Claude_in_Chromeでブラウザを自動操作しよう — 日本語でブラウザ自動化
  7. ClaudeCode機能編/07_ポートフォリオサイトを作ってみよう — 実績サイト制作＆デザインYAML
  8. ClaudeCode機能編/08_GitHubを使ってソースを管理しよう — コミット・プッシュを日本語で

  2. NotionDB編/02_LINE広告データを分析してみよう — KPIとチャートの使い分け
  3. NotionDB編/03_ECサイトの売上を集計して疑似的ピボットテーブルを作ってみよう — 型指定と集計

💡 全体を貫く「マネタイズの型」

  1. 手動で1回成功させる → スキル化 → 一言で再現（作業の資産化）
  2. 情報収集 → 整形 → 発信 → 管理 の自動パイプライン（コンテンツ工場）
  3. データ取得 → 集計 → 可視化 → 報告（分析・運用代行の月次業務）
  4. モックを最速で作って見せる営業（動くデモで受注する）
  5. 安全設計（APIキー管理・権限制御）を語れることが法人案件の入場券
