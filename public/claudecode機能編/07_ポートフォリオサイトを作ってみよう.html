07_ポートフォリオサイトを作ってみよう【実践】（課題3-07）

このページはなにを学ぶpage？

これまでAIで作った成果物を「実績」としてまとめたポートフォリオサイト（作品集サイト）を作り、インターネットに公開（デプロイ）するまで学ぶ。デザインの指定方法、複数AIの並列作業、画像生成AIの組み込みまで扱う。

重要ポイント

初級：作成から公開までの流れ

  1. 実績画像を集める：過去の成果物のスクリーンショットをフォルダにまとめる（Claude in Chromeに自動で集めさせてもOK）
  2. 参考サイトをリサーチさせる：「テーマに合った参考サイトを見つけて構造を提案して」と頼む
  3. 最小構成のMOC（試作）で方向性を確認：いきなり完成品を作らせず、小さく作って方向を確かめる
  4. デザインをYAMLで指定：指定しないと「よくありがちな退屈なサイト」になる
  5. 実装＆デプロイ：「本格的に実装して、github pagesでデプロイしてください」

デザインYAMLという強力なテクニック

  • 好きなサイトのデザインを「抽象化」してYAMLファイル（設定メモ）にし、自分のサイトに流用する：
このサイトデザインを抽象化して配色や、雰囲気などをprompt yamlにしてください。
具体的な文言やレイアウトは対象外とします。
まったく別のサイトにも流用できるように抽象化してください
【参考URL】
  • **「気に入ったデザインを言葉のレシピにして使い回す」**という考え方。一度作れば全案件で使える資産になる。

中級：Dynamic Workflows（複数エージェントの並列処理）

  • 設定でダイナミックワークフローを有効化すると、複数のAIエージェントが役割分担して同時に作業してくれる（リサーチ係・実装係・デザイン係が並行で動くイメージ）。
  • 注意：通常より使用量（トークン）を多く消費する。

上級：画像生成AIを組み込む

  • ヒーローセクション（サイト最上部の大きな見せ場）や背景画像を、GPT Image 2.0で生成して使う。
  • 画像生成プロンプトの構造が参考になる：コンセプト／スタイル指定／構図とレイアウト／カラーパレット／装飾・ディテールに分けて書くと質が安定する。

公開先の選択肢

  • GitHub Pages：GitHubの無料ホームページ公開機能。
  • Vercel：無料プランでも使えるサイト公開サービス。「git hubへの反映とvercel cliを使用してデプロイしてください」で進められる。
  • つまずいたらスクリーンショットを撮ってAIに相談すればよい。

用語解説

  • ポートフォリオ：自分の作品・実績をまとめた作品集。仕事を受注するときの営業ツールになる。
  • デプロイ：作ったサイトやアプリをインターネット上に公開すること。「配備する」という意味。
  • GitHub Pages（ギットハブ・ページズ）：GitHubが提供する無料のWebサイト公開機能。
  • Vercel（ヴァーセル）：Webサイトを簡単に公開できるサービス。無料プランあり。
  • CLI（シーエルアイ）：文字コマンドでソフトを操作する方式。Vercel CLIはコマンドでデプロイできる道具。
  • MOC／モック：最小限の試作品。方向性確認のために小さく作るもの。
  • YAML（ヤムル）：「項目名: 値」形式で設定を書くファイル形式。デザインの指示書としても使える。
  • 抽象化：具体的なものから「本質・共通ルール」だけを取り出すこと。ここでは特定サイトの文言を除き、配色や雰囲気だけをルール化すること。
  • Dynamic Workflows（ダイナミックワークフロー）：Claudeが状況に応じて複数のエージェントを自動編成し、並列で作業させる機能。
  • 並列処理：複数の作業を同時に進めること。順番待ちがなくなるので速い。
  • ヒーローセクション：サイトを開いて最初に見える大きなメインビジュアル部分。
  • カラーパレット：使う色の組み合わせセット。
  • APIキー：外部サービス（画像生成など）を利用するための「利用者証明の鍵」。他人に見せてはいけない。

マネタイズへのヒント💰

  • ポートフォリオは案件獲得の必須アイテム。クラウドソーシングやSNS営業では「何が作れるか」を見せられる人から仕事が決まる。この課題の成果物自体が営業資産。
  • デザインYAML集を作っておけば、「テイスト別デザインテンプレート」として制作の高速化・品質安定化ができ、薄利の案件でも利益が出る体質になる。
  • GitHub Pages／Vercelの無料公開を知っていると、サーバー費ゼロでお客様に本番サイトを納品できる。
