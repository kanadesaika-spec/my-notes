# 05_API活用フローをスキル化して反復作業を簡単に再現してみよう【実践】（課題4-05）

## このページはなにを学ぶpage？
タスク管理ツール「Asana」のAPIを題材に、**「一度うまくいったAPI作業の流れをスキル化して、次からは一言で再現する」**方法を学ぶ。反復作業と「車輪の再開発」（同じものを何度も作り直すムダ）をなくすのが目的。

## 重要ポイント
### 初級：AsanaのAPIでタスク追加
1. Asana（asana.com）に登録
2. 設定→アプリ→デベロッパーコンソール→**個人アクセストークンを新規作成**（トークンは再発行不可。なくしたら作り直し）
3. Claudeに「トークン＋APIドキュメントのURL＋タスク内容」を渡して実行：
```
以下でasanaAPIでタスクを追加してください
個人アクセストークン 【トークン】
APIドキュメント https://developers.asana.com/reference/rest-api-reference
タスク内容はこちら
# タスクグループ名
## タスクカテゴリ
- タスクA
- タスクB
```
- ここでも**「APIドキュメントのURLを渡して読ませる」**のが鉄板パターン。

### うまくいった流れを資産化する2つの魔法プロンプト
1. **スキル化**（この課題の核心）：
```
call Agents claude-code-guideに準拠してここまでのFBをskills、Rules、Sub agents、scripts、CLAUDE.mdのいずれかの今回の生成に関わった該当の箇所をアップデートして（.claude内に該当ものがない場合は新規作成）
```
2. **設定の保存**：
```
.envに今実行した内容ですべて保存しておいてください
```
→トークンだけでなくプロジェクトIDやカテゴリ情報も保存され、次回から即再現できる。

### 中級：再現テスト
- 新しいセッションで「このタスクをasana『〇〇』に追加して」と言うだけで、**スキルが自動発動してタスクが追加される**。初回に苦労した手順が一言になる。

### 上級：確認作業までAIに任せる
- 「URLを開きタスクが問題なく追加されていることを確認して」→Claude in Chromeが実際にページを開いて目視確認までしてくれる。
- **実行＋検証をセットで自動化する**という発想が大事（やりっぱなしにしない）。

## 用語解説
- **Asana（アサナ）**：チームのタスク（やること）を管理する有名なWebサービス。
- **個人アクセストークン**：APIを使うための個人用の合言葉。パスワードと同じ扱いで管理する。
- **反復作業**：毎回同じ手順を繰り返す作業。自動化の第一候補。
- **車輪の再開発**：すでにある仕組みを知らずにゼロから作り直してしまうムダのこと。「車輪」はすでに発明されているのだから、作り直すなという戒め。
- **FB（フィードバック）**：ここでは「ここまでのやりとりの内容」の意味。
- **Rules／scripts／CLAUDE.md**：Claude Codeの設定ファイル群。Rulesはルール集、scriptsは小さなプログラム置き場、CLAUDE.mdはプロジェクトの取扱説明書。
- **セッション**：AIとの1回の作業のまとまり。新しいセッション＝まっさらな状態から開始。
- **デベロッパーコンソール**：開発者向けの管理画面。

## この課題の本質（応用の型）
```
①手動でAPI作業を成功させる
　↓
②「ここまでの流れをスキル化して」と頼む
　↓
③設定は.envに保存させる
　↓
④次回からは一言で再現、確認までAIがやる
```
この型は**Asanaに限らず、あらゆるWebサービスのAPI（Slack・Gmail・freeeなど）に使い回せる**。

## マネタイズへのヒント💰
- 「お客様の使っているツール（タスク管理・会計・チャット）にAIをつなぎ、定型作業を一言で終わるようにする」＝**業務自動化の導入支援サービス**の基本形がこれ。
- 一度作ったスキルは他の案件にも流用できる。**案件をこなすほど自分のスキル資産がたまり、納品が速く・安くなる**という好循環を作れる。
- 「実行だけでなく確認までAIがやる」設計は、品質保証として提案書に書ける差別化ポイント。
