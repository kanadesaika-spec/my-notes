# 04_X APIでバズる投稿を生成して自動投稿してみよう【実践】（課題4-04）

## このページはなにを学ぶpage？
X（旧Twitter）のAPIを使って、**①自分のポストデータを取得→②Notionに保存してバズるパターンを分析→③分析結果をナレッジ化してAIに投稿文を作らせ、自動投稿する**という、SNS運用の自動化フルコースを学ぶ。※最低課金5ドル。

## 重要ポイント
### X APIの料金の仕組み
- 2026年2月からPay-Per-Use（従量課金）が標準プラン。
- **投稿1回あたり約0.015ドル（約2.3円）、読み取り1件あたり0.005ドル（約0.8円）**。
- 前払いクレジット制（最低5ドル）＋**「支出上限」を必ず設定して使いすぎを防ぐ**のがお作法。

### 初級：ポストデータの取得
1. X Developer Portal（developer.x.com）でアプリを作成
2. 3つのキー（コンシューマーキー・Secret Key・ベアラートークン）をコピー
3. .envファイルに設定して、Claudeに指示：
```
.envのX APIキーを使って、自分のアカウントの最新投稿を取得して 【アカウントURL】
```
4. 「取得結果をCSV形式で保存して」→本文・いいね数・リポスト数・インプレッション数（表示回数）が取れる

### 中級：Notionに保存して分析
- Notionの「インテグレーション（コネクト）」を作成→シークレットキー取得→対象ページに接続を追加→データベースIDをURLから取得→.envに設定。
- 「X APIで取得したポストデータを、Notionのデータベースに保存して」で自動保存。
- 分析の指示例：「インプレッション数順に並べて、バズっている投稿の共通パターンを分析して」
- **実運用の分析軸3つ**：
	1. **投稿数**（どのくらいの頻度で投稿しているか）
	2. **バズる型**（伸びる投稿に共通する構成。例：1行目に「速報」）
	3. **情報密度**（有益情報・オリジナル視点があるか）
- キーワード検索で競合のポストも取得→**競合リサーチの自動化**ができる。

### 上級：ナレッジ化→生成→自動投稿
1. 分析結果を「ナレッジファイル」にまとめる（バズった投稿のテンプレート／効果的キーワード／自分のジャンルに合うトーン）。**ナレッジの質＝生成される投稿の質**。
2. 「ナレッジを参照して、〇〇ジャンルでバズりそうな投稿を5本生成」
3. 投稿にはOAuth 1.0キーなど追加の認証設定が必要（アプリ権限を「読み込みと書き込み」に変更）。
4. 「生成した投稿の〇番目をX APIで投稿して」で自動投稿完了。

### 重要な注意点
- **Xのオートメーションルール（自動投稿の利用規約）の遵守が必要**。ボットラベルの設定・アカウント紐付けが実質必須。スパム判定でアカウント停止・API停止のリスクあり。
- APIキー・アクセストークンは絶対に公開しない。

## 用語解説
- **X API**：Xのデータ（投稿・いいね数など）にプログラムからアクセスできる仕組み。
- **Pay-Per-Use（従量課金）**：使った分だけ払う料金方式。
- **X Developer Portal**：X APIを使うための開発者向け管理画面。
- **コンシューマーキー／ベアラートークン**：APIを使うための認証キーのセット。役割の違う複数の鍵がある。
- **OAuth（オーオース）**：「このアプリに、あなたのアカウントの操作を許可する」ための標準的な認証の仕組み。投稿（書き込み）にはこの設定が必要。
- **インプレッション数**：投稿が表示された回数。バズ分析の基本指標。
- **リポスト**：他人の投稿を自分のフォロワーに再共有すること（旧リツイート）。
- **CSV**：カンマ区切りの表データ形式。Excelやスプレッドシートで開ける。
- **インテグレーション（コネクト）**：Notionと外部サービスをつなぐ接続設定。
- **データベースID**：NotionのデータベースをAPIから指定するための識別番号（URLに含まれる）。
- **ナレッジ**：AIに参照させる「知識データ」。ここではバズる投稿の型やコツをまとめたファイル。
- **オートメーションルール**：Xが定める自動投稿に関する利用規約。
- **ボットアカウント**：自動で動くアカウント。Xでは「自動化されたアカウント」であることの表示が求められる。

## マネタイズへのヒント💰
- **これはSNS運用代行ビジネスの設計図そのもの**：データ取得→分析→ナレッジ化→生成→投稿のループを回せれば、複数アカウントの運用を1人で回せる。
- 「バズ分析レポート」は単体でも商品になる（競合アカウント分析レポートの販売、コンサル資料など）。
- 自動化のリスク管理（規約遵守・スパム判定回避・支出上限）を知っていることが、代行業としての信頼の土台。**規約違反でクライアントのアカウントを飛ばしたら終わり**なので、この知識は必須。
