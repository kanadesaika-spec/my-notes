# 01_GPT Images 2.0のAPIで画像生成をしてみよう【実践】（課題4-01）

## このページはなにを学ぶpage？
画像生成AI「GPT Images 2.0」を、**fal**というAPIプラットフォーム経由で使い、Claudeから画像を自動生成させる方法を学ぶ。APIキーの取得・管理という「外部サービスをAIにつなぐ基本」が身につく回。※最低課金10ドル（プリペイド式）が必要。

## 重要ポイント
### falとは・お金の仕組み
- fal（fal.ai）＝**いろいろな生成AIのAPIを取りそろえたプラットフォーム**。GoogleやGitHubアカウントでログインできる。
- **10ドルからのプリペイド（前払い）課金**。クレジットの利用期限は365日。
- クレジット不足だと生成エラーになるので残高を確認する。

### APIキーの取得と管理（最重要）
1. falのSettingタブ→「Add key」→用途メモを書いて「Create Key」
2. 表示されたキーをコピー
3. **キーが流出すると不正利用される。秘密事項として厳重管理**
- Claudeには「falのAPIキーです .envで管理してください」と渡す方法が紹介されているが、**厳密にはチャット欄にAPIキーを貼るのはリスクがある**。より安全なのは自分で.envファイルを作って保存する方法。

### APIの種類を選ぶ
- **text-to-image**：文字から画像を生成（今回使うのはこちら）
- **image-to-image**：画像から別の画像を生成

### 生成の流れ
1. APIドキュメント（説明書）のURLをClaudeに渡して読ませる：
```
以下のドキュメントページからGPT Image 2 APIの使い方を取得してください
https://fal.ai/models/openai/gpt-image-2/api
```
2. 生成プロンプトを実行（スタイル指定の書き方が参考になる）：
```
fal APIでGPT Image 2画像を生成して、ローカルファイルとして保存してください
生成内容は以下です

（表現したい内容）を以下のスタイルで表現
Japanese educational infographic style, "Kawaii" vector illustration, flat design with bold black outlines, ...
Color palette: Bright pastel colors, soft gradients, cheerful and pop atmosphere.
Decorations: Scattered sparkles, stars, hand-drawn decorative icons, ...
```
- **「ドキュメントを読ませてからやらせる」**のがAPI連携の鉄板手順。人間がAPIの仕様を覚える必要がない。

### 中級・上級
- 中級：この流れをスキル化する（`.claude/skills` 配下の正しい記法で）→「/gen-img」のように1コマンドで画像生成できるようになる
- 上級：Webサーチと組み合わせ「リサーチ結果を画像化する」ワークフローに発展させる

## 用語解説
- **API（エーピーアイ）**：プログラム同士をつなぐ「窓口」。APIを使うと、他社のAI機能を自分の仕組みに組み込める。
- **APIキー**：APIを使うための「利用者証明の鍵」。料金はこのキーの持ち主に請求されるので、流出厳禁。
- **fal（ファル）**：多数の生成AI APIをまとめて使えるプラットフォームサービス。
- **GPT Images 2.0**：OpenAI社の画像生成AIモデル。
- **プリペイド課金**：先にお金をチャージして、使った分だけ減っていく方式。使いすぎ防止になる。
- **クレジット**：チャージした残高のこと。
- **text-to-image／image-to-image**：「文字→画像」「画像→画像」の生成方式。
- **.env（ドットエンブ）ファイル**：APIキーなどの秘密情報を書いておく専用ファイル。プログラム本体と分けることで、うっかり公開するのを防ぐ。
- **ドキュメント**：APIの使い方の説明書。URLをAIに渡せば読んで理解してくれる。
- **ダッシュボード**：サービスの管理画面。
- **ローカルファイル**：自分のパソコンの中に保存されるファイル。

## マネタイズへのヒント💰
- **API経由の画像生成は「原価が見えるサービス」を作れる**：1枚あたり数円〜数十円のコストで、バナー・アイキャッチ・図解の制作サービスを提供できる。
- 「APIキーを安全に管理する」「ドキュメントをAIに読ませて連携する」スキルは、あらゆる外部サービス連携（決済・メール・SNS投稿など）に応用が効く。**AIサービス開発の基礎体力**。
- リサーチ→画像化のワークフローは、SNS図解投稿の量産・教材制作などに直結する。
