# 07_Bitwarden Secrets Manager で .env を卒業しよう【上級】（課題4-07）

## このページはなにを学ぶpage？
APIキーを .env ファイルに書く管理をやめて、**Bitwarden Secrets Manager**というサービスでクラウド上に暗号化保存し、アプリ起動時だけ安全に渡す方法を学ぶ。さらに、Claude Codeが**うっかりキーの値を画面に出してしまうコマンドをブロックする設定**まで仕上げる。AI時代のセキュリティ実務の重要回。

## 重要ポイント
### なぜ.envだと危ないのか
- .envは**同じ環境にいるどのプログラムからも読めてしまう**。AIエージェントが作業中に.envを見つけて、**応答の中にAPIキーを貼り付けてしまう事故が実際に報告されている**。
- .envをうっかりGitHubにpushしてしまう事故も多発。

### Secrets Managerの仕組み
- APIキーはクラウド上で暗号化保存され、**ローカルにファイルとして残らない**（送信前に手元で暗号化されるので、Bitwardenのサーバーにも平文では届かない）。
- `bws run -- <起動コマンド>` で、**起動したプログラム（子プロセス）の環境変数にだけ**キーが注入される。画面やログには値が出ない。
- **Machine Account（プログラム専用アカウント）**をアプリごとに分けると、漏洩時の被害をそのアカウント分だけに限定できる。
- ※1PasswordやDopplerなど他のサービスでも同様のことが可能。

### 手順の骨組み（初級）
1. Web UIでプロジェクト作成→シークレット登録（Nameは環境変数名と同じに。例：GEMINI_API_KEY）
2. Machine Accountを作成→プロジェクトへの**Read権限をGrant access**（これを忘れると後で一覧が空になる定番ミス）→Access Token発行（**この時しか表示されない。必ずコピー**）
3. bws CLIのインストールはClaude Codeに頼んでよい
4. **Access Tokenの値だけは絶対にAIに渡さない**。手順のひな形だけ作らせて、値の貼り付けは自分の手で行う
5. `bws run -- python アプリ.py` で「.envなし起動」を確認

### 中級：AIに「値を出すコマンド」を禁止させる
`~/.claude/settings.json` の permissions.deny に登録：
```json
{
  "permissions": {
    "deny": [
      "Bash(bws secret list*)",
      "Bash(bws secret get*)",
      "Bash(printenv*)",
      "Bash(env)"
    ]
  }
}
```
- denyルールは ask/allow より**必ず優先される**（評価順：deny→ask→allow）。
- 設定後は「実際に拒否されるか」をAI自身にテストさせて確認する。

### 事故ったときの対応
- トークンを画面共有やGitに貼ってしまったら：**即Revoke（無効化）→新トークン発行→設定を上書き**。

## 用語解説
- **シークレット**：APIキー・パスワード・トークンなど「秘密にすべき値」の総称。
- **Bitwarden（ビットウォーデン）**：有名なパスワード管理サービス。Secrets Managerは同じ会社の**開発者向けシークレット管理**という別サービス。
- **bws CLI**：Bitwarden Secrets Managerをコマンドで操作する道具。
- **Machine Account（マシンアカウント）**：人間ではなくプログラム用のアカウント。アプリごとに分けて権限を最小にする。
- **Access Token**：Machine Accountがアクセスするための合言葉。発行時にしか表示されない。
- **環境変数**：プログラムに外から渡す設定値。OSの「連絡メモ」のようなもの。
- **子プロセス**：あるプログラムから起動された別のプログラム。`bws run` は子プロセスにだけ値を渡す。
- **平文（ひらぶん）**：暗号化されていない、そのまま読める状態のデータ。
- **暗号化**：他人が読めない形にデータを変換すること。
- **permissions.deny**：Claude Codeで「このコマンドは実行禁止」と指定する設定。
- **Revoke（リボーク）**：発行済みのトークンを無効化すること。漏洩時の第一手。
- **棚卸し**：持っているものを全部書き出して整理すること。
- **PreToolUse Hook**：Claude Codeがツールを実行する直前に割り込んで検査できる仕組み。denyより確実なブロック手段。

## マネタイズへのヒント💰
- **セキュリティは法人案件の入場券**。「APIキーをどう管理していますか？」に答えられない業者は企業に採用されない。この仕組みを運用できることが受注の前提条件になる。
- 「AIエージェント導入＋シークレット管理の整備」をセットで提案できると、単なる自動化屋との差別化になる（事故防止の設計まで含めた提案）。
- 自分のサービス運営でも、キー漏洩は**他人のお金を使われる事故**に直結する。従量課金APIを使うビジネスでは必須知識。
