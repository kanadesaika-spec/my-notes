# ようこそ 👋

Obsidianでまとめている学習メモの公開サイトです。左のエクスプローラーか検索（Ctrl+K）から自由に見てください。

## 🕸️ グラフビュー（どのメモとどのメモがつながっているか）

右側に表示されているのが**グラフビュー**です。丸ひとつがメモ1枚、線がメモ同士のつながりを表しています。

- **全体を一気に見る**：`Ctrl + G`（Macは `Cmd + G`）を押すか、グラフ右上の拡大アイコンをクリック → 全メモの関係が広がります
- 丸にマウスを乗せると、そのメモとつながっているものだけが光ります
- 丸をクリックするとそのメモへ移動。ドラッグ・ズームもできます
