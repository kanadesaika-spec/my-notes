# 01_デザインを指定してWebサイトを作ろう（課題7-01）

## このページはなにを学ぶpage？
Google AI Studioの「**Build**」機能で、プロ級のデザインパーツを組み合わせた日本語の企業Webサイトを自動生成し、Googleの「**Cloud Run**」で公開（デプロイ）するまでを学ぶ。

## 重要ポイント
### プロンプトの作り方（デザインコードを渡すテクニック）
1. デザイン参考サイト **Tailwind Plus**（tailwindcss.com/plus）のHero Sections集から好きなデザインを選ぶ
2. 表示を**HTMLからReactに切り替えてから**コードをコピー
3. 以下のテンプレートに貼り込む：
```
# 依頼
日本語の企業Webサイトを作成してください

## テーマ
【Webサイトのテーマを入力】

## Hero Sections
【コピーしたコードを貼り付け】

## その他のパーツ
Hero Sectionsに合わせて適切なデザインを反映してください
```
- **「お手本のコードを渡して、残りをそれに合わせさせる」**のがコツ。文章でデザインを説明するより確実にプロ級の見た目になる。

### Buildでの生成
- aistudio.google.com → 左メニューの「Build」→プロンプト送信
- **複数のデザイン案が提示され、矢印で見比べて選べる**（Select this design）
- エラー時は「**Fix**」ボタンで自動修正。それでもダメなら**最初から作り直した方が早い**ことが多い。

### Cloud Runへのデプロイ
- Build画面右上の「publish」→ Google Cloudプロジェクトを作成→支払い情報を設定（無料クレジットが付与される）→「Publish app」
- 軽いプロジェクトなら数十秒で公開完了、URLが発行される。
- **課金設定に抵抗があれば「Share」→「Public: Anyone with the link can view」で共有だけもできる**。

### 課金トラブルを防ぐ削除方法（重要）
- Publish→プロジェクト選択→「Advanced Settings」→Cloud Runの「サービス」→チェックを入れて削除。
- **使わないアプリは削除する**のがクラウド課金の基本マナー。削除後もキャッシュでページが見えることがあるので、キャッシュクリアして確認する。

## 用語解説
- **Google AI Studio**：Googleの生成AI（Gemini）を使える開発ツール。無料から使える。
- **Build（ビルド）**：AI Studioの中の、チャット指示だけでWebアプリを自動生成してくれる機能。
- **Hero Section（ヒーローセクション）**：Webサイトの最上部にある大きなメインビジュアル部分。第一印象を決める。
- **Tailwind（テイルウィンド）CSS**：世界的に人気のデザイン用コード集。Tailwind Plusはその公式有料テンプレート集（一部無料）。
- **React（リアクト）**：Webサイトの画面を作るための人気プログラム部品の仕組み。Buildと相性が良い。
- **Cloud Run（クラウドラン）**：Google Cloudのアプリ公開サービス。作ったアプリをネット上で動かせる。
- **デプロイ**：作ったものをインターネットに公開すること。
- **Google Cloud プロジェクト**：Googleのクラウドサービスを使うときの管理単位（財布とフォルダを兼ねたもの）。
- **無料クレジット**：新規登録時にもらえるお試し残高。
- **キャッシュクリア**：ブラウザにたまった古い表示データを消して、最新状態を読み込み直すこと。

## マネタイズへのヒント💰
- 「Tailwindのプロ級デザイン＋AI生成」の組み合わせで、**デザイナー並みの見た目のサイトを短時間で納品**できる。制作単価と時間のバランスが劇的に良くなる。
- Cloud Runのデプロイと削除・課金管理を知っていることは、**お客様のクラウド費用を守る提案**ができるということ。信頼につながる。
- デザインパーツ集（Tailwind Plus等）を引き出しとして持っておくと、提案時に「この見た目にできます」と具体例を見せられる。
