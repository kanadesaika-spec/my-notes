# 02_シューティングゲームを作ろう（課題1-02）

## このページはなにを学ぶpage？
Claude Codeでの**「はじめての開発」体験**。作業フォルダの用意→アプリの基本設定→日本語プロンプト1つでシューティングゲームを作り、ブラウザで遊べる状態にする（目安：約8分）。開発の基本操作がすべて詰まった回。

## 重要ポイント
### 開発前の準備手順（毎回の基本の型）
1. **作業フォルダを作る**：デスクトップか書類フォルダに「ユニコスクール」フォルダを作成
2. Claude Desktop Appを起動→左上の**Codeタブ**へ切り替え
3. 「Gitが必要です」と警告が出た場合だけGitをインストール（出なければ飛ばしてOK）
4. **作業フォルダを指定**：「ローカル」横のフォルダ選択から作ったフォルダを選ぶ
5. **許可モードを設定**：チャット欄下のモード選択から選ぶ

### 許可モードの安全ルール（重要）
- 迷ったら**安全確認のあるモード（「許可を確認」等）**を選ぶ。
- 「**許可をバイパス**」は確認なしでAIがどんどん操作するモード。**大切なファイルが入っていない作業フォルダでのみ使う**。

### モデル設定
- 使える高性能モデルを選択。わからなければ初期状態のままでOK。

### プロンプトを送信
```
HTMLで超作り込んだオリジナリティのあるシューティングゲームを作って下さい！完成したらブラウザでサイトOpen
```
- 「完成したらブラウザでサイトOpen」まで書くと、**完成後に自動でブラウザが開いて確認できる**。

### 開発中のコミュニケーション（一生使える基本）
- AIから質問されたら「**お任せします！**」でOK。こだわるなら「もっと派手にして」「夜空の背景にして」と日本語で伝える。
- 真っ白な画面が出たら：「画面が真っ白です。原因を確認して、正常に表示されるように修正してください。」
- エラーが出たら：**エラー文を全文貼り付けて**修正を依頼する。エラーは自分で解読しなくてよい。

## 用語解説
- **シューティングゲーム**：弾を撃って敵を倒すタイプのゲーム。プログラミング学習の定番題材。
- **作業フォルダ（ローカルフォルダ）**：AIが作ったファイルの保存先になるフォルダ。プロジェクトごとに分けるのが基本。
- **Codeタブ**：Claude Desktop Appの中の、Claude Code（開発機能）を使う画面。
- **許可モード**：AIがファイル操作やコマンド実行をする前に「確認を求めるか」の設定。
- **許可をバイパス**：確認をスキップして自動で進めるモード。速いが、安全のため使う場所を選ぶ。
- **モデル**：AIの頭脳の種類。高性能モデルほど賢いが、使用量の消費も大きい。
- **プロンプト**：AIへ送る指示文。
- **HTML**：Webページを作るための基本の言語。ブラウザだけで動くのでゲームの試作にも使える。
- **ブラウザ**：Webページを見るソフト（Chrome、Edgeなど）。

## マネタイズへのヒント💰
- 「日本語1行でゲームが完成する」体験は、**AIで何が作れるかをお客様に見せるデモとして最強**。営業や説明会の「つかみ」に使える。
- 「フォルダ指定→許可モード→プロンプト→確認→修正」の流れは、この後のすべての開発（HP制作・業務ツール・アプリ）に共通する**受託業務の基本動作**。
- 「エラー文を貼れば直る」ことを知っているだけで、外注せずに自力で納品物を完成させられる＝利益率が上がる。
