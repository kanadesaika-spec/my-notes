# 01_Claude Codeを導入しよう（課題1-01）

## このページはなにを学ぶpage？
AI開発の相棒となる「Claude Code」を自分のパソコンで使える状態にする、**すべての課題の出発点**。アプリのインストール→アカウント作成→有料プラン（Pro）への加入までを行う（目安：約10分）。

## 重要ポイント
### 導入は3ステップ
1. **インストール**：MacまたはWindows用のClaude Desktop App（デスクトップアプリ）を公式クイックスタートからインストール
2. **アカウント作成**：「Continue with Google」でGoogleアカウントを使うのが簡単（メールアドレスでも登録可）
3. **課金**：**無料プランのままではClaude Codeは使えない**。Pro以上のプランへの加入が必須

### お金まわりの注意（つまずきポイント）
- 申込み画面には「**月間／年間**」の切り替えがある。**年間が選ばれていると1年分がまとめて請求される**ので、まず試すなら「月間（月払い）」に切り替えてから決済する。
- 最初はProプランの月払いから始めればOK。

### 完了の確認
- ログイン後に**Codeタブを開けること**を確認できれば導入成功。
- Windowsで「Gitが必要です」と表示された場合は、ページ内の該当セクションに対処法がある（Gitという道具を追加インストールする）。

## 用語解説
- **Claude Code（クロードコード）**：Anthropic社のAI「Claude」に、パソコン上でのファイル作成・プログラミング・作業実行までさせられる開発ツール。チャットで指示するとAIが実際に手を動かしてくれる。
- **Claude Desktop App**：Claudeをパソコンにインストールして使うアプリ版。この中の「Codeタブ」からClaude Codeが使える。
- **Proプラン**：Claudeの有料プラン（月額約20ドル）。Claude Codeを使うにはPro以上が必要。
- **インストール**：アプリをパソコンに入れて使える状態にすること。
- **サインアップ（Sign up）／ログイン（Log in）**：新規登録／すでに持っているアカウントで入ること。
- **Billing（ビリング）**：料金・支払いの設定画面のこと。
- **月払い／年払い**：料金を毎月払うか、1年分まとめて払うか。年払いは割安だが最初に大きな金額が請求される。
- **Git（ギット）**：ファイルの変更履歴を管理する道具。Claude Codeの動作に必要になる場合がある。

## マネタイズへのヒント💰
