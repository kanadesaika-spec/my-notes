# 05_Claude Code Desktopを使いこなそう（課題1-05）

## このページはなにを学ぶpage？
Claude Code Desktopの便利機能——**複数セッション（作業の同時並行）、2画面表示、権限モードの切り替え、ペイン配置、サイドチャット**——を一通り試す（目安：約15分）。「AIを1人ではなく複数人の部下のように使う」感覚を身につける回。

## 重要ポイント
### 複数セッションで作業を並行させる（この課題の核心）
- **セッション1（分析係）**：
```
現在のプロジェクトを確認して、改善できそうな点を3つ提案してください。今回はファイルを変更せず、提案だけを表示してください。
```
- **セッション2（文書係）**：1つ目を閉じずに新しいセッションを追加して：
```
このプロジェクトのREADME.mdを作成してください。プロジェクトの概要、起動方法、主な機能を、初めて見る人にも分かるようにまとめてください。
```
- **役割を分けて同時に走らせる**＝複数の作業が並行して進む。2画面表示（左右または上下）にすると、片方の作業中にもう片方の状態を確認できる。
- 「ファイルを変更せず、提案だけ」という**読み取り専用の頼み方**も安全に使う大事なテクニック。

### 権限モードの使い分け（代表的な4モード）
| モード | 動き |
|---|---|
| Ask permissions | ファイル変更などの前に毎回確認する（安全） |
| Auto accept edits | ファイル編集を自動で許可（速いが注意） |
| Plan mode | すぐ編集せず、計画や手順だけ作る |
| Auto | 自動実行向けモード（利用可能な場合） |
- **Shift + Tab** で切り替えられる場合がある。
- 🛡️ **自動許可モードは課題用フォルダでのみ**。重要なファイルがあるフォルダでは確認ありのモードを使う。
- 大切な実データや個人情報が入ったフォルダはそもそも作業対象にしない。

### その他の便利機能
- **ペイン配置**：セッションの表示位置を変えたり、コードの表示領域を広げたりできる。
- **サイドチャット**：作業と別枠でAIに質問できる小窓。例：「いま進めている2つの作業の違いと、それぞれの進捗を簡潔に整理してください。」
- **セッションの整理**：名前を分かりやすく付ける・並べ替える・終わったものは閉じる。増えてきたときの管理習慣。

## 用語解説
- **セッション**：AIとの1つの作業スペース。複数作れば複数の仕事を同時に進められる。
- **マルチセッション**：複数のセッションを並行で使うこと。
- **ペイン**：画面の分割された1区画のこと。窓ガラスの「1枚」のイメージ。
- **サイドチャット**：メイン作業とは別に開ける補助チャット。作業を止めずに質問できる。
- **権限モード**：AIの操作にどこまで自動許可を与えるかの設定。
- **README.md（リードミー）**：プロジェクトの説明書ファイル。「これは何か・どう動かすか」を最初に読む人向けに書く。開発の必須マナー。
- **ステータスバー**：画面端にある、現在のモードや状態を表示する帯。
- **ショートカット**：キーボード操作で素早く機能を呼び出す方法（Shift+Tabなど）。

## マネタイズへのヒント💰
- **マルチセッションは「1人で複数案件を回す」ための技術**。A案件の実装を走らせながら、B案件の分析を進める——時間あたりの生産性が直接、収入に響く。
- 「分析係・文書係のように役割を分ける」発想は、SubAgent（本格的なAIチーム化）への準備運動。
- READMEを常に整備する習慣は、納品物の引き継ぎ資料として顧客評価に直結する。
