# 02_音声をテキスト化する文字起こしシステムを作ろう（課題2-03）

## このページはなにを学ぶpage？
自分の声を録音して、AIに文字起こしさせてObsidianの保管庫にためる方法を学ぶ。
①1回だけの文字起こし（初級）→②文章をきれいに整える（中級）→③コマンド1つで全部自動でやる仕組み＝ワークフロー作り（上級）へと進む。
※Obsidian編のSTEP3「インプット取得②・自動化の入口」。

## 重要ポイント
### 初級：音声を文字にする
- 録音はMacやWindowsの標準アプリでOK。思いついたことを一方的にしゃべるだけでよい。
- 音声ファイルはコピー＆ペーストでObsidianの保管庫に入れられる。形式は.m4aのままでよい（.mp3や.wavなど一般的な形式ならAIが処理できる）。
- Claudeデスクトップアプリで「@ファイル名」でファイルを指定（メンション）して依頼する：
```
@xxxx  音声の文字起こしをして、ファイルに記載してください
```

### 中級：文字起こしをきれいに整える
```
思考を整理するために書き起こしデータをテーマごとにまとめて
新規作成したマークダウンファイルに記載してください
obsidianフロントマターを日本語で記載して
```
- ただの文字の羅列を「テーマごとの整理＋タグ付け」までAIにやらせるのがポイント。

### 上級：コマンド1つの自動ワークフローを作る
- フォルダを2つ作る：「00ボイスメモ」（音声の入れ場所）と「01文字起こし」（結果の出力先）。
- AIに「transcribeスキル」（自動処理の手順書）を作らせると、以後は音声を入れて `/transcribe` と打つだけで、文字起こし→整形→保存→処理済み音声の移動まで全自動になる。
- スキルを作ったらClaudeデスクトップアプリの**再起動が必要**。
- ワークフロー設計で大事な指示のコツ：
	- 処理済みファイルは `processed` フォルダへ移動させる（二重処理を防ぐ）
	- **「音声の内容を推測したり、ダミーテキストを使ってはならない」と禁止事項を明記する**（AIがサボって嘘のデータを作るのを防ぐ）
	- 日付・元ファイル名・タグをフロントマターとして自動で付けさせる
- AIが勝手にWhisper API（有料の文字起こしサービス）を使おうとしたら、「APIキーは使いたくないので別の方法でやりなおして」と言えば回避できる。

## 用語解説
- **ワークフロー**：仕事の一連の流れを決めた「作業手順書」。一度作れば同じ作業を自動で繰り返せる。
- **スキル**：Claudeに覚えさせる「技」のこと。手順書ファイル（.md）として保存し、`/コマンド名` で呼び出せる。
- **メンション（@）**：「@ファイル名」のように@を付けて、特定のファイルや人を指し示すこと。
- **フロントマター**：ノートの先頭に書く「ファイルの名札」部分。日付・タグ・タイトルなどの情報（メタデータ）をまとめて書く。Obsidianではこの情報で検索や整理ができる。
- **YAML（ヤムル）**：フロントマターを書くときの書式のルール。「項目名: 値」の形で書く。
- **タグ**：ノートに付ける分類ラベル。「#文字起こし」のように付けて、後から仲間のノートをまとめて探せる。
- **アーカイブ**：使い終わったものを捨てずに、別の場所へ保管しておくこと。
- **Whisper API（ウィスパーAPI）**：OpenAI社の文字起こしAIをプログラムから呼び出す有料サービス。APIは「プログラム同士をつなぐ窓口」、APIキーは「その利用者証明書（鍵）」のこと。
- **埋め込みリンク（![[ファイル名]]）**：Obsidianで他のファイルをノートの中に直接表示する書き方。音声ならノート内で再生できる。
- **.m4a / .mp3 / .wav**：音声ファイルの形式（種類）の名前。

## マネタイズへのヒント💰
- **「議事録の自動作成サービス」がそのまま作れる**。会議・インタビュー・セミナーの録音を入れるだけで整形済み議事録が出てくる仕組みは、企業向けに売れる定番サービス。
- 「録音→文字起こし→整形→保存」を自動化する体験は、あらゆる業務自動化サービスの基本形。**「人がやっていた繰り返し作業をコマンド1つにする」＝お金を払ってもらえる価値**。
- 音声で思考をためる習慣は、自分のコンテンツ（ブログ・教材）の素材集めにもなる。
