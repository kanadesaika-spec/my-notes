# 05_GitHubリポジトリで保管庫を管理しよう（課題2-06）

## このページはなにを学ぶpage？
Obsidianの保管庫（ためてきたノート全部）をGitHubに登録して、バックアップ・変更履歴の記録・自動化の土台にする方法を学ぶ。
※Obsidian編のSTEP6（最終回）「管理・バックアップ」。これで「集める→整える→発信する→管理する」の流れが完成する。

## 重要ポイント
### GitHubを使う4つのメリット
1. **クラウドバックアップ**：保管庫をGitHubに保存しておけば、パソコンが壊れてもデータが残る
2. **変更履歴が残る**：いつ・どのファイルを・どう変えたかが全部記録される
3. **AIと連携しやすい**：GitHub上のファイルをAIに読ませられる
4. **自動化の入口になる**：GitHub Actionsで定期実行・自動整理などを組み込める

### 初級：リポジトリ（保管場所）を作る
- GitHubのアカウントを作ったら、細かい設定はAIに任せられる：
```
GitHub CLIのアカウント連携を設定してください
```
```
このフォルダをprivate repositoryとしてgithubにリポジトリを作成してください
```
- **private（非公開）にするのが大事**。自分のメモを世界に公開しない設定。

### 中級：変更をGitHubに反映（プッシュ）する
- ファイルを追加・編集したら、チャットで「**プッシュして**」と言うだけで反映できる。
- 記事作成プロンプトの例には「2000文字以上」「Web検索も活用」「プロのライター風の口調」「絵文字で感情を出す」など、**文章の質を指示で細かくコントロールするテクニック**が詰まっている。

### 上級：GitHub Actionsで「自動で情報がたまる仕組み」を作る
プロンプト例（自分用に書き換えて使う）：
```
リポジトリ https://github.com/username/repo に GitHub Actions ワークフローを作成してください。

【要件】
- スケジュール: 毎日日本時間10:00（UTC 01:00）に実行
- 処理内容: （指定URL）から最新5件の記事を取得
- 保存形式: articles/YYYY-MM-DD_HHMMSS/ フォルダに1記事1ファイル（.md）で保存
- 取得後、自動でリポジトリにコミット＆プッシュする
- 手動実行も可能にする（workflow_dispatch）
- 作成後、テスト実行して動作確認する
```
- **自分が寝ている間も毎日情報が自動で集まる**。要件を箇条書きで明確に書くのが成功のコツ。

## 用語解説
- **GitHub（ギットハブ）**：ファイルの変更履歴をクラウドで管理できる世界最大級のサービス。エンジニア向けのイメージが強いが、文章ファイルの保管・バックアップにも使える。
- **リポジトリ**：GitHub上の「プロジェクトごとの保管箱」。保管庫1つ＝リポジトリ1つのイメージ。
- **リモートリポジトリ**：自分のPC（ローカル）ではなく、インターネット上（リモート）にある保管箱のこと。
- **プッシュ**：自分のPCでの変更をリモートリポジトリへ「押し上げて」反映すること。
- **コミット**：変更内容を「ここまでやった」と記録すること。セーブポイントを作るイメージ。
- **private repository（プライベートリポジトリ）**：自分（と許可した人）しか見られない非公開の保管箱。
- **GitHub CLI（シーエルアイ）**：GitHubを文字コマンドで操作する道具。CLIは「コマンドラインインターフェース」の略で、マウスではなく文字入力で操作する方式のこと。
- **GitHub Actions（アクションズ）**：GitHub上で「決めた時間に決めた処理を自動実行」できる仕組み。無料枠があり、自動化の定番。
- **UTC**：世界標準時。日本時間はUTC+9時間（日本の10:00はUTCの1:00）。
- **RSS（アールエスエス）**：ブログやニュースサイトの新着記事を機械が読み取りやすい形式で配信する仕組み。自動収集の素材によく使う。
- **workflow_dispatch（ワークフローディスパッチ）**：GitHub Actionsを「手動でもボタンで実行できる」ようにする設定。
- **Obsidian-Git**：ObsidianからGit操作ができるようにするコミュニティプラグイン。

## マネタイズへのヒント💰
- **GitHub Actionsの定期自動実行は、ほぼ無料で動く「自動情報収集サービス」の基盤**。業界ニュースの自動収集→要約→配信、のようなサービスの土台になる。
- 「データのバックアップと変更履歴の管理」は、法人相手にシステムやコンテンツを納品するときの必須スキル。信頼につながる。
- ここまでのObsidian編全体で、**「情報が自動で集まり、記事になり、発信され、安全に保管される」個人メディア工場**が完成する。これはSNS運用・ブログ運営・情報販売のすべての土台。
