# 03_最新情報を毎朝届けるLINE公式アカウントを作成しよう（課題5-03）

## このページはなにを学ぶpage？
Yahoo!ニュースのIT記事上位5件を毎朝9時に**LINE公式アカウントへ自動配信する仕組み**を、Manusで作る。ニュース配信だけでなく、**サービス情報やお客様向けメッセージの自動送信に応用できる**実践的な内容。Manusの無料枠で実践可能。

## 重要ポイント
### 全体の構造（LINE連携の基本形）
LINE公式アカウントと外部ツールをつなぐには「**チャネルアクセストークン**」という鍵が必要で、取得には3つの準備がいる：
1. **プロバイダー**（提供者となる入れ物）を作成 — LINE Developers Console（developers.line.biz）で
2. **LINE公式アカウント**を作成
3. **両者を連携**（Messaging APIを有効化）
→「Messaging API設定」タブの一番下でチャネルアクセストークンを発行・コピー

### ManusとLINEの連携
- Manusの設定→「コネクタ」→LINEを検索して接続
- チャネルアクセストークンと、自分の「ユーザーID」（LINE Developersのチャネル基本設定にある）を貼り付けて接続完了

### スキル作成と定期実行
1. Manusのチャット欄「+」→「スキルを使用」→skill-creatorで：
```
yahooニュースの最新記事を集めて 最新のものを5件、タイトルとURLをまとめてLINE MCPで送信する スキル を作成してください
```
2. 完成したら「マイスキルに追加」
3. 定期タスク化：
```
毎回このスキルを実行する定期タスクとして毎日朝9時に実行させてください
```
4. 設定→「スケジュールタスク」で「今すぐ実行」でテスト→OKなら「有効」をオン

### Manusのスキルとは
- AIに仕事のやり方を覚えさせて何度でも使えるようにする機能。特徴は「専門性の向上」「手順の自動化」「拡張性」。（Claude CodeのSkillsと同じ発想）

### 通知が届かないときのチェックリスト
- プロバイダーと公式アカウントが連携できているか
- チャネルアクセストークンを正しくコピペしたか
- ユーザーIDを正しくコピペしたか
- スケジュールタスクがオンになっているか

## 用語解説
- **LINE公式アカウント**：お店や企業がLINEで情報配信できるビジネス用アカウント。
- **プロバイダー**：LINEの開発機能における「アカウントの提供者・親フォルダ」のような入れ物。
- **LINE Developers Console**：LINEの開発者向け管理画面。
- **Messaging API**：LINEのメッセージをプログラムから送受信できる仕組み。
- **チャネルアクセストークン**：Messaging APIを使うための鍵。外部ツール連携に必須。漏らさないこと。
- **ユーザーID**：LINE上の自分を識別する番号。表示名とは別物。
- **コネクタ**：Manusと外部サービスをつなぐ接続機能。
- **MCP（エムシーピー）**：AIと外部サービスをつなぐ標準規格（Model Context Protocol）。「LINE MCPで送信」＝MCP経由でLINEに送るという意味。
- **スケジュールタスク（定期タスク）**：決まった時刻に自動実行される処理。
- **スクリプト**：一連の処理を書いた小さなプログラム。ここではPythonで自動生成される。

## マネタイズへのヒント💰
- **LINE公式アカウントの自動配信は、店舗・スモールビジネス向けの定番商材**。「毎朝の業界ニュース配信」「新商品情報の自動配信」「予約リマインド」などを月額サービスとして提供できる。
- LINEは日本で最も開封率が高い配信チャネル。メルマガより読まれるため、**顧客との接点作りの提案として刺さりやすい**。
- この課題の構造（情報取得→整形→LINE送信→定期実行）は、送信先をSlackやメールに変えるだけで企業向け社内通知サービスにもなる。
