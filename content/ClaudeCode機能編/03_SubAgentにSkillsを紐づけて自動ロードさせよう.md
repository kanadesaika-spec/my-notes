# 03_SubAgentにSkillsを紐づけて自動ロードさせよう【入門】（課題3-03）

## このページはなにを学ぶpage？
SubAgent（専門担当のAI）に、Skills（専門知識のマニュアル）を**最初から持たせておく**方法を学ぶ。SubAgentの設定ファイルのフロントマターに `skills:` と書くだけで、起動時に自動でスキルが読み込まれる（自動ロード）。

## 重要ポイント
### 紐づけの仕組み
- SubAgentの設定ファイル（.md）のフロントマター（先頭の設定欄）に `skills: スキル名` を書く。
- するとSubAgentが起動した瞬間からその専門知識を持った状態で仕事を始められる。
- 複数のスキルはカンマ区切りで指定できる：
```
skills: database-tips, security-checks, performance-guide
```

### 実例：SEOブログ執筆エージェント
- 文字数カウントスキル（char-count）を作っておき、それを持たせた「seo-blog-writer」SubAgentを作る。
- 「5000文字の記事を書いて」と頼むと、**スキルで文字数を測りながら本文を伸ばしたり縮めたりして、指定文字数に合わせてくれる**。
- AIは普段、正確な文字数を数えるのが苦手。**苦手なことは道具（スキル）で補わせる**のが上手な使い方。

### 発展ヒント：手作業をそのままワークフロー化する裏ワザ
- 複雑なSubAgentを最初から設計するのは難しい。**まず普段の手順を1つずつAIにやらせて、うまくいったら最後にこう言う**：
```
ここまでの流れを call Agents claude-code-guide に準拠して .claude 内に全部作って、
CLAUDE.mdまたは /.claude 内の正しいフォルダに設置
```
- 「実際に動いた手順」をそのままエージェント定義に変換してくれる。**設計してから作るのではなく、動かしてから固める**という実践的な考え方。

### よくあるトラブル
- スキルが読み込まれない→ `skills:` の値とスキルのnameが**大文字小文字まで完全一致**しているか確認。
- どのスキルが使われたかわからない→「〇〇スキルを使って」と明示すれば確実。
- スキル内のプログラム（Pythonなど）が実行されない→SKILL.mdに「このスクリプトを実行して」と明記＋SubAgentにBash（コマンド実行）ツールの権限が必要。

## 用語解説
- **自動ロード**：起動と同時に自動で読み込むこと。
- **紐づけ（ひもづけ）**：AとBを関連付けて、セットで動くようにすること。
- **SEO（エスイーオー）**：「検索エンジン最適化」。Googleなどで検索したとき、自分の記事が上位に表示されるようにする工夫のこと。ブログ集客の基本技術。
- **フロントマター**：ファイル先頭に書く設定情報の欄。ここに `skills:` を書いて紐づける。
- **CLAUDE.md**：プロジェクトのルールや説明をClaudeに伝えるための特別なファイル。プロジェクトの「取扱説明書」。
- **Bashツール**：パソコンにコマンド（文字の命令）を実行させる道具。プログラムの実行にはこの権限が必要。
- **マルチエージェント協調**：複数のAIエージェントがチームのように協力して1つの仕事を仕上げること。
- **ライブラリ**：よく使う部品（スキルなど）を集めた「図書館」のような共有置き場。

## マネタイズへのヒント💰
- 「SEO記事を指定文字数ぴったりで量産するエージェント」は、**記事作成代行・コンテンツSEO事業でそのまま使える**構成。
- 「スキル×エージェントの組み合わせで専門家AIを作る」発想は、業種特化AI（不動産専門・美容専門など）を作って売るときの設計図になる。
- 「動いた手順をそのままエージェント化する」方法は、**お客様の業務をヒアリング→一緒に一度やってみる→自動化して納品**という受託の流れに直結する。
