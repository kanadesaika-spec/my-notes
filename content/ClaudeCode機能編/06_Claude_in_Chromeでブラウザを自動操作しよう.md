# 06_Claude in Chromeでブラウザを自動操作しよう【実践】（課題3-06）

## このページはなにを学ぶpage？
「Claude in Chrome」＝日本語で指示するだけでブラウザを自動操作できるAnthropic公式のChrome拡張機能を学ぶ。ニュースの見出し取得（データ抽出）→フォームの自動入力→複数サイトをまたぐ情報収集ワークフローへとステップアップする。

## 重要ポイント
### 使うための条件
- **有料Claudeプラン（Pro／Max／Team）が必要**。無料プランでは使えない。
- **Google Chrome限定**（Brave、Arcなど他ブラウザは非対応）。
- 初回起動時のモード選択：初心者は「Ask before acting（実行前に確認）」が安心。慣れたら「Act without asking（確認なしで実行）」。

### 初級：データ抽出（Webスクレイピング）を体験
```
https://news.yahoo.co.jp/ を開いてください
```
```
このページに表示されているニュースの見出しを10個取得して、
箇条書きで表示してください
```
- プログラミングなしで、日本語だけでWebページから情報を取り出せる。

### 中級：フォームの自動入力
- 取得したデータをスプレッドシートに書き込ませる練習ができる（※ベータ版のため動作が不安定なことがある）。
- 練習用テストサイト（the-internet.herokuapp.com）なら公開されたテスト用ログイン情報で安全に自動入力を試せる。

### 上級：複数サイトをまたぐワークフロー
- Claudeデスクトップアプリから「**Chromeと連携してください**」と言うだけで連携できる。
- 例：Yahoo・NHK・朝日の3サイトからトップニュースを取得→サイトごとに整理して一覧表示。**情報収集→整理までを一連の自動処理**にできる。

### トラブル対処と安全ルール
- **ログインとCAPTCHA（ロボット確認）はAIは代行しない**→手動で対応してから「続けてください」と伝えると再開する。
- 操作が固まる→ページ読み込みを待つ／確認モードにする／**複雑な操作は小さなステップに分割する**。
- セキュリティの鉄則：
	- 銀行・証券など金融サイトでの自動操作は避ける
	- パスワードや個人情報の自動入力は信頼できるサイトのみ
	- 機密情報を扱うページでの使用は控える

## 用語解説
- **Claude in Chrome**：Chromeの画面横にClaudeのパネルを出して、日本語の指示でブラウザを操作させられる公式拡張機能。
- **拡張機能**：ブラウザに後から追加できる機能。Chromeウェブストアからインストールする。
- **自然言語**：プログラミング言語ではなく、人間が普段話す言葉（日本語や英語）のこと。
- **Webスクレイピング**：Webページから必要な情報を自動で抜き出す技術。
- **フォーム**：Webページ上の入力欄（名前・メールアドレスなどを入れる欄）のこと。
- **CAPTCHA（キャプチャ)**：「私はロボットではありません」のような、人間かどうかを確認する仕組み。AIには突破させないルールになっている。
- **サイドパネル**：ブラウザ画面の横に開く補助画面。
- **ベータ版**：正式公開前の「試験版」。動作が不安定なことがある。
- **フィールド**：フォームの中の1つ1つの入力欄のこと。
- **スプレッドシート**：Google製の表計算ソフト（Excelのようなもの）。
